<h1 align="center">Pomidor Cam</h1>

<p align="center">
  <strong>AI-таймер Помодоро с контролем присутствия по камере для Android: локальный детектор YOLO26, вспышка с настройкой яркости, полноэкранная заставка отдыха на Ubuntu/Windows и журнал рабочего дня с автовыгрузкой.</strong>
</p>

---

## Принцип работы

1. **Автоматический контроль присутствия:** Каждые **10 секунд** (настраивается от `5` до `60` сек) Pomidor Cam делает кадр с камеры в фоне — в том числе при выключенном экране — и проверяет, есть ли человек за рабочим столом.
2. **Тихий старт фокуса:** Если никого нет в кадре, таймер не запускается. Как только вы садитесь за стол, без лишних уведомлений начинается **20-минутный** таймер фокуса (настраивается от `1` до `120` мин).
3. **Защита от кратких отлучек:** Параметр **допуска пропусков (`1–5` подряд)** позволяет отвернуться или ненадолго отойти, не срывая текущую сессию.
4. **Двойной сигнал об отдыхе:** Когда непрерывная сессия успешно завершена:
   - **Вспышка телефона:** Фонарик моргает **3 раза** (настраивается `1–5` раз и яркость **`10%–100%`** через API яркости Android 13+ либо адаптивную длительность импульса на Android 11–12 / Helio G95).
   - **Сигнал на компьютер по LAN:** Приложение отправляет `HTTP POST` (`/pomodoro/break`) и `UDP`-пакет по локальной сети, открывая на **Ubuntu** или **Windows** полноэкранную заставку **5-минутного отдыха**.

## Основные возможности

- **Оптимизация под Infinix Note 10 Pro и мульти-камеру:**
  - Поиск всех модулей через Camera2 + CameraX (`CameraCatalog`): фронтальная (`16 МП`), основная (`64 МП`), физическая широкоугольная камера и резервный широкоугольный режим через минимальный зум `0.6×`.
  - Фоновый foreground-сервис с `WakeLock` (`PomidorMonitorService`) для стабильной работы с выключенным экраном на MediaTek Helio G95 (8 ГБ ОЗУ).
- **Локальный YOLO26 + встроенный детектор:**
  - Импорт собственных моделей **YOLO26 `.onnx`** (ONNX Runtime) и **`.tflite`** через системный выбор файлов, а также резервный встроенный детектор (режим `Авто`).
  - Настройка порога уверенности (`20%–90%`).
- **Журнал рабочего дня (`06:00 – 04:00`) и утренняя автовыгрузка:**
  - Фиксирует все сессии — и завершённые непрерывные помидоры, и прерванные уходом или остановленные вручную — в рамках рабочего дня (по умолчанию с `06:00` до `04:00` следующего утра).
  - Выгрузка полного отчёта (**JSON + Markdown**) на ПК по локальной сети, а также сохранение в файл или отправка через системное меню.
  - **Автоматическая утренняя выгрузка:** Планировщик `WorkManager` (`MorningReportWorker`) каждое утро (после выбранного часа, по умолчанию `08:00`) автоматически отправляет на ПК отчёт за предыдущий рабочий день и повторяет попытку, если компьютер был выключен.
- **Язык интерфейса:**
  - По умолчанию используется **английский язык**, в **Настройках** доступно мгновенное переключение на **Русский**, **English** или **Системный (EN/RU)**.
- **Скрипт для ПК (`pomidor_pc_overlay.py`):**
  - Лёгкий скрипт на чистом Python (`tkinter` + стандартная библиотека), который можно сохранить, скопировать или отправить прямо со вкладки **ПК-мост**.
  - Закрывается **одним нажатием `Esc`** (или используйте `--strict` для блокировки `Esc` на время отдыха) и сохраняет отчёты в папку `./pomidor_reports/`.

## Экспорт модели YOLO26

Выгрузите модель в ONNX и импортируйте её в разделе **Настройки → Детектор ИИ → Импорт `.onnx` / `.tflite`**:

```bash
# Оптимально для Infinix Note 10 Pro (Helio G95) — быстрая проверка каждые 10 секунд
yolo export model=yolo26n.pt format=onnx imgsz=640 simplify=True

# Повышенная точность, если телефон стоит далеко от стола (медленнее на CPU)
yolo export model=yolo26s.pt format=onnx imgsz=640 simplify=True
```

> **Про `yolo26m` / `yolo26l` и `imgsz=1280`:** Увеличение разрешения до `1280` и переход на тяжёлые модели повышают точность на дальнем расстоянии и для мелких объектов, но кратно увеличивают задержку и нагрев на мобильном процессоре Helio G95. Для определения одного человека за столом с интервалом 10 секунд лучший баланс дают `yolo26n` или `yolo26s` с `imgsz=640`.

## Настройка на Ubuntu и Windows

Сохраните или скопируйте `pomidor_pc_overlay.py` со вкладки **ПК-мост** в приложении и запустите на компьютере в той же локальной сети Wi-Fi:

### Ubuntu / Linux
```bash
sudo apt install python3-tk
python3 pomidor_pc_overlay.py --port 8765
```

### Windows
```powershell
python pomidor_pc_overlay.py --port 8765
```

Дополнительные параметры:
- `--port 8765` — порт для HTTP и UDP (должен совпадать с настройкой в приложении).
- `--strict` — запрещает закрывать заставку клавишей `Esc`.

Во вкладке **ПК-мост** укажите локальный IP компьютера (например, `192.168.1.100`), нажмите **Сохранить** и проверьте связь кнопками **Пинг ПК** или **Тест заставки**.

## Сборка Android-приложения

- **Требования:** JDK 17+, Android SDK (Compile SDK 36.1, Min SDK 24), Gradle.
- **Стек:** Kotlin, Jetpack Compose (Material 3), CameraX + Camera2, Room, DataStore, WorkManager, ONNX Runtime Android, LiteRT/TFLite, ML Kit Object Detection.

```bash
# Сборка debug APK
gradle assembleDebug

# Запуск JVM unit-тестов
gradle :app:testDebugUnitTest \
  --tests "com.example.PomodoroSessionEngineTest" \
  --tests "com.example.WorkdayClockAndReportTest" \
  --tests "com.example.Yolo26DecoderTest" \
  --tests "com.example.CameraCatalogAndTorchTest" \
  --tests "com.example.MorningAutoExportTest"
```
